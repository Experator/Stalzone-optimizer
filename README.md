# STALZONE OPTIMIZER

**Десктопное приложение для оптимизации игры STALZONE.**

Приложение анализирует характеристики ПК, определяет производственный тир, и применяет 27 методов оптимизации: CPU affinity, RAM cleanup, GPU power management, network tweaks, диск, сервисы, визуальные эффекты и игровые настройки.

## Возможности

- **Анализ комплектующих** — CPU, GPU, RAM, диски, ОС, дисплей
- **Оценка производительности** — Low / Mid / High / Enthusiast (score 0-100)
- **27 оптимизаций** в 9 категориях:
  - Питание (power plan, timer resolution, core parking)
  - Процессор (affinity, priority, Game DVR)
  - Память (standby cleanup, periodic cleanup, swap, cache)
  - Видеокарта (power management, HWA, TdrDelay)
  - Сеть (Nagle off, DNS flush, network throttling)
  - Диск (indexing, defrag, TRIM)
  - Сервисы (SysMain, DiagTrack, Windows Search)
  - Визуальные (effects, transparency)
  - Игры (kill bg apps, Game Mode, HAGS)
- **Мониторинг в реальном времени** — CPU/RAM/Swap, загрузка по ядрам, статус процесса игры
- **Кастомизация оптимизаций** — включение/отключение каждого метода
- **Прямое применение** — оптимизации применяются непосредственно из GUI
- **Откат изменений** — возврат всех изменений при необходимости

## Требования

- **ОС:** Windows 10/11 (Тестировалось на 11 Pro 25H2), Linux, macOS
- **Python:** 3.10+ (для запуска из исходников)
- **Права:** Администратор (для работы многих оптимизаций которые работают напрямую с редактором реестра и т.д)

## Запуск из исходников

```bash
# 1. Установить зависимости
pip install -r requirements.txt

# 2. Запустить
python main.py
```

## Компиляция в .exe (Windows)

```cmd
# Запуск скрипта build.bat
```

После сборки: `dist\stalzone optimizer.exe` — исполняемый файл, работает на любом Windows ПК без установленного Python.

## Компиляция в Linux/macOS

```bash
chmod +x build.sh
./build.sh
```

Результат: `dist/stalzone optimizer`

## Использование

### Вкладка «Обзор»
- Просмотр характеристик ПК
- Оценка тира производительности (score, FPS,)
- Мониторинг CPU/RAM в реальном времени

### Вкладка «Оптимизации»
- 27 функций в 9 категориях
- Кнопки: «Только рекомендованные», «Включить все», «Выключить все»
- Каждый тоггл показывает: impact, требуется ли admin, рекомендован ли

### Вкладка «Настройки»
- Имена процессов игры
- Приоритет процесса (Above Normal / High / Realtime)
- Режим CPU Affinity (физические / все ядра)
- Разрешение таймера (0.5–1.5 мс)
- Интервал очистки RAM (60–900 сек)
- Агрессивная очистка RAM

### Нижняя панель
- **«Применить оптимизации»** — применяет все включенные оптимизации
- **«Отменить изменения»** — откатывает изменения

## Примечания

- Большинство оптимизаций работают **только на Windows** (powercfg, reg, sc, wmic)
- На Linux/macOS приложение запускается, показывает характеристики, но оптимизации пропускаются
- Для полной функциональности запускайте от имени администратора

## Безопасность

- Все изменения реестра бэкапятся перед изменением
- Сервисы возвращаются к исходному состоянию при выходе
- `disable_swap_file` доступен только при RAM ≥ 16 ГБ
- Все операции логируются в консоль
